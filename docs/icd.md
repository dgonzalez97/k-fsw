# Interface control document {#icd}

Every parameter and command the reference image carries. This page is generated by asking a running `linux` image, so it cannot describe something the firmware does not have.

The mode column is what the parameter service enforces: `r` is read only, `w` is writable, and `b` means the value is kept across a reset.
